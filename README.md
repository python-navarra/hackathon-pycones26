# Hackathon PyConES 2026

Repositorio con los ejercicios propuestos para el hackathon de PyConES 2026. Cada carpeta contiene un reto con su enunciado, ejemplos de entrada/salida y una posible solución en Python.

## Descripción

Este proyecto reúne una colección de problemas inspirados en la temática de la conferencia PyConES, con retos de distintos niveles: desde ejercicios muy básicos de saludo y cálculo, hasta problemas de strings, conteo, optimización y concurrencia.

La idea es practicar Python resolviendo problemas reales de programación competitiva, combinados con una narrativa divertida y temática del evento.

## Objetivo

Practicar Python con ejercicios temáticos, mejorar la lógica de programación y experimentar con distintos tipos de problemas: desde cálculos sencillos hasta algoritmos y concurrencia.

## Licencia
