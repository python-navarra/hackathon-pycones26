## Story

PyConES 2026 has finally begun! Everyone is talking, meeting new people, and sharing their love for Python. You can almost smell Python in the air.

The organizers have a brilliant idea: they want to know **how many times the word `Python` is mentioned** during the conference.

So they start counting:
- One time. 
- Two times.
- One hundred times.
- One thousand nine hundred and ninety-nine times...

Wait... there are too many! They will never finish counting them all by hand.

One of the organizers has an idea:

*"We need a Python program to count them for us!"*

The computer is ready. The editor is open. It's time to write some code.

## Problem Statement

Given a string, count how many times the word `Python` appears in it.

The word must be counted only when it appears exactly as `Python`, with the same capitalization.

## Input Format

A single line containing a string.

## Constraints

- The string contains between **1 and 100,000 characters**.
- The string contains only **English letters** and spaces.
- The word `Python` may appear zero or more times.

## Output Format

A single integer with the number of times `Python` appears in the string.
